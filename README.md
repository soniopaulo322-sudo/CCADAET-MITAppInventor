## GitHub Workflow
- Created a public GitHub repository.
- Uploaded the MIT App Inventor `.aia` project file.
- Created the `feature/week3` branch.
- Recorded each improvement in a separate commit.
- Created a Pull Request from `feature/week3` to `main`.

## How to Open the Project
1. Download the `.aia` file from this repository.
2. Open [MIT App Inventor](https://ai2.appinventor.mit.edu/).
3. Select **Projects → Import project (.aia) from my computer**.
4. Choose the downloaded `.aia` file.

The purpose of this activity is to practice repository management, version control, branching, commits, and Pull Requests using GitHub.
